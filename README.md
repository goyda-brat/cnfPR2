Практическая работа №2, вариант 24. Инструмент для работы с графом зависимостей пакетов Rust (Cargo).

Настройки хранятся в файле формата INI в разделе depgraph. Параметр package_name задаёт имя анализируемого пакета. Параметр repository_url задаёт адрес репозитория, он должен начинаться с http:// или https://, а в тестовом режиме это путь к файлу тестового репозитория. Параметр test_mode включает или выключает режим работы с тестовым репозиторием, допустимые значения true и false. Параметр filter_substring задаёт подстроку для фильтрации пакетов, она не должна содержать пробелов, и этот параметр можно не указывать.

В тестовом режиме имя пакета должно состоять только из больших латинских букв, например A. В обычном режиме имя пакета может содержать латинские буквы, цифры, дефис и подчёркивание и должно начинаться с буквы.

Пример файла настроек: в первой строке пишется [depgraph], дальше по одной строке package_name = serde, repository_url = https://index.crates.io, test_mode = false и filter_substring = proc.

Чтобы запустить программу в Windows, достаточно запустить файл run.bat. Можно также выполнить в терминале команду python src/goyda.py config.ini. Если имя файла с настройками не указать, программа возьмёт config.ini. При запуске программа печатает все настройки в формате ключ = значение, по одному параметру в строке. Код завершения 0 означает успех, код 2 означает ошибку в настройках.

Для настроек из примера программа выведет четыре строки: package_name = serde, repository_url = https://index.crates.io, test_mode = false и filter_substring = proc. Если в настройках есть ошибка, программа выводит понятное сообщение, например такое: Ошибка: адрес репозитория должен начинаться с http(s)://

Описание функций из файла src/goyda.py.

Функция read_config(path) читает INI-файл и возвращает раздел depgraph. Если файл не найден, имеет неверный формат или в нём нет раздела depgraph, функция сообщает об ошибке.

Функция get_value(section, key) возвращает значение обязательного параметра. Если параметр не задан или пустой, функция сообщает об ошибке.

Функция check_test_values(package, repository) проверяет значения для тестового режима. Имя пакета должно состоять из больших латинских букв, а файл тестового репозитория должен существовать.

Функция check_real_values(package, repository) проверяет значения для обычного режима. Имя пакета должно состоять из допустимых символов и начинаться с буквы, а адрес репозитория должен начинаться с http:// или https://.

Функция check_config(section) проверяет все настройки сразу и возвращает их в виде словаря. Она сообщает об ошибке, если обязательный параметр не задан, значение test_mode не равно true или false, либо подстрока фильтрации содержит пробел. Дальше она вызывает проверку для нужного режима.

Функция print_config(config) печатает настройки в формате ключ = значение.

Функция main(path) является главной. Она читает файл настроек, проверяет их и печатает. При ошибке она выводит сообщение и возвращает код 2.

Все ошибки внутри программы оформлены как ValueError с понятным текстом, а главная функция перехватывает их и показывает пользователю сообщение.
